# ATTI v0.2.0

Adds Arabic-focused and Arab-developed tokenizers to the `current_law_v2` benchmark. The corpus is unchanged and still **provisional**: no pair is human-approved.

## Highlights

- **Two tokenizers developed in the region have a negative Arabic token tax.** ALLaM's (NCAI/SDAIA, Saudi Arabia) has a TTR of 0.798, a −20.2% tax, with 6,097 Arabic and 7,645 English tokens. The K2 Horizon tokenizer (IFM, MBZUAI, UAE), also used by Jais 3, has a TTR of 0.835, a −16.5% tax, with 6,015 Arabic and 7,202 English tokens.
- **Fanar 2** (QCRI, Qatar) uses Google's Gemma 3 tokenizer unchanged: TTR 1.206, +20.6%.
- **AceGPT v2 32B** ships the Qwen1.5 tokenizer. It gives the same ids as the existing Qwen2.5 result on all 200 texts, so it is not reported as a separate row.
- **AraGPT2 Mega** (American University of Beirut) is reported separately (TTR 0.431). It is an Arabic-only tokenizer whose English costs 1.9× the median tokens per character.
- **ArabianGPT V2** is excluded because its tokenizer maps Arabic diacritics to its unknown token. **Falcon-H1 Arabic** has no public tokenizer and was not substituted.

## Method

- New command, `atti regional`. It uses the same 100 pairs, whitespace normalization, metrics and special-token policy as before, and only the `raw_content_tokens` method; provider API counts stay separate.
- It downloads only allow-listed tokenizer files at pinned revisions, checked by SHA-256. No model weights are downloaded and no repository code is run.
- Every text must pass the coverage, special-token, round-trip and determinism guards. A tokenizer is listed as equivalent when its token ids match another's on all 200 texts, and the scope of that equivalence is recorded.
- Model developers and tokenizer origin are recorded separately, and so are model license declarations and upstream tokenizer terms.
- Results include TTR without Articles 34, 35 and 108 for every tokenizer.
- **Failure handling:** an unverifiable or failed run writes nothing and exits with code 2. A run that would change a published regional result, equivalence or exclusion is refused with exit code 4.

## Dependencies

- `sentencepiece==0.2.1` is new, in the `regional` dependency group. It is the official runtime used for the ALLaM tokenizer and the Fanar 2 reference check. `uv sync` installs it, but it is not a dependency of the `atti` package. No other locked version changed.

## Unchanged

- Every v0.1.0 result, report, manifest and review file is byte-identical.
- All existing tokenizer pins and API anchors are unchanged.
- The new results live in their own files: `results/current_law_v2_regional*`, `reports/current_law_v2_regional.md` and `manifest/regional_tokenizers.json`.
