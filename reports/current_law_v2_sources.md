## Extraction

- arabic_pdf: PyMuPDF; lines classified by font size (13.9 headings, 12.0 body, 10.6 repealed marker, <9 footnotes/markers excluded, >=16 titles); blocks read top-to-bottom
- arabic_cleanup: presentation forms -> base letters (NFKC on those code points only); justification tatweel removed; mirrored ( ) [ ] { } swapped back
- english_html: selectolax; article = <h4>Article N:</h4> + following blocks until the next article or section title; <ol> numbers reconstructed as 'N.'
- counting_normalization: every whitespace run -> one space, ends stripped (unchanged from v1); applied after extraction cleanup
- arabic_confirmation: PDF text must equal the HRSD Arabic HTML text (ignoring HTML-only tatweel/ZWNJ); otherwise the article is excluded, not repaired
